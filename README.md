# I feel Slovenia — redesign concept

Homepage redesign concept for [slovenia.info](https://www.slovenia.info/sl), with a clean, fintech-inspired art direction. Content, photography and logo come from the official site.

## Run locally

```bash
node server.mjs
```

Then open http://localhost:4317.

## Stack

Plain HTML, CSS and JS. Geist and Geist Mono (Google Fonts), GSAP + ScrollTrigger, Lenis.
